# Тикет №12 Допилить слаш-меню и редактор для редактирования существующих блоков

## Описание

Допилить слеш меню, перевести на русский, добавить недостающие действия для редактирования существующих блоков (например, изменение типа блока, удаление блока, добавление блока выше/ниже). Добавление возможности управления стрелочками в рамках слеш-меню. И изменение дизайна слайдера на подходящий под ux/ui редактора
