# Добавление действий по нажатию на колонку в wikitables

## Цель
Добавить возможность выполнять действия при нажатии на определенные колонки в wikitables. Это может быть полезно для быстрого выполняния операцияций, таких как редактирование, удаление или просмотр деталей записи. А также сортировка, фильтрация, группировка и другие действия, которые могут быть полезны для пользователей при работе с данными в wikitables.


## Требования 
1. Должно появляться меню действий при нажатии пкм на название определенной колонки в wikitables. 
2. При наведении на название колонки должно появляться меню "3 точки", при клике на которое должно открываться меню действий для этой колонки.
3. В меню действий должны быть следующие пункты: "Изменить название поля", Сортировать А -> Я и Я -> А, "Скрыть колонку", "Показать все колонки", "Группировать по этой колонке", "Фильтровать по этому значению". Группировать по "Название колонки", добавить "Название колокнки" как фильтр, удалить поле.
4. При выборе пункта "Изменить название поля" должно открываться окно для ввода нового названия колонки, и после подтверждения изменения, название колонки должно обновляться в wikitables.
5. При выборе пункта "Сортировать А -> Я" или "Сортировать Я -> А" данные в wikitables должны сортироваться по выбранной колонке в соответствующем порядке.
6. При выборе пункта "Скрыть колонку" выбранная колонка должна скрыться из отображения в wikitables, но данные в ней должны сохраняться и быть доступными для других действий.
7. При выборе пункта "Показать все колонки" все скрытые колонки должны отображаться в wikitables.
8. При выборе пункта "Группировать по этой колонке" данные в wikitables должны группироваться по значениям выбранной колонки, и отображаться в виде групп с возможностью раскрытия каждой группы для просмотра ее содержимого.
9. При выборе пункта "Фильтровать по этому значению" должно открываться окно для ввода значения, и после подтверждения фильтрации, данные в wikitables должны отображаться только для строк, где значение в выбранной колонке соответствует введенному значению.

## Требования к реализации

Предварительно изучить бэкенд, чтобы в случае чего добавить необходимый эндпоинт, если их нехватает. 
Преиспользовать сущесвующий функционал для сортировки, фильтрации и группировки данных в wikitables.
При реализации на фронтенеде использовать скиллы.
