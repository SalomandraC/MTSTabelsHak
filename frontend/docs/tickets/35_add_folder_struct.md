# Улучшение структуры папок в проекте

## Цель

Необходимо добавить возможность создавать папки, переминовывать их, перекладывать туда файлы с помощью drag and drop и при наведении на три точки перемещать через стрелочки или модалку

## Требования

обязатеьно проверить можно ли с бэкенда wikiLive переимновывать папки создавать папки и перемещать файлы, если нет, то нужно будет добавить эти эндпоинты

## Задачи
1. Добавить функционал создания папок в интерфейс.
2. Реализовать возможность переименования папок.
3. Реализовать функционал перемещения файлов в папки с помощью drag and drop.
4. Добавить возможность перемещения файлов в папки через меню, открывающееся при наведении на три точки, с помощью стрелочек или модалки.
5. Убедиться, что все изменения сохраняются и отображаются корректно в интерфейсе.
6. При реализации на фронтенде использовать скиллы.
