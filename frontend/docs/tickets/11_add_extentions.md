# Тикет 11: Добавить расширения Tiptap 

## Цель
- Добавить возможность менять и добавлять ссылки
- Добавить возможность указывать язык кода, который описывается 
- Добавить возможность добавлять выравнивание текста 
- Добавить возможность добавлять картинку в текст
- Добавить возможность добавлять чеклист в текст
- Добавить шорткаты для md синтаксиса (например, `#` для заголовков, `-` для списков и т.д.)

## Статус
- ✅ Добавлены markdown shortcuts через Tiptap extensions `Highlight` и `Typography` в `PageEditor`.
- ✅ Базовые markdown input-rules от `StarterKit` активны (`#`, `##`, `>`, `-`, `*`, `1.` и т.д.).
- ✅ Сборка `npm run build` проходит без ошибок.
- ✅ Добавлен checklist через `TaskList` + `TaskItem` extensions.
- ✅ Чеклист доступен в slash-меню (`Чеклист`) и в toolbar (`Task`).
- ✅ Добавлена вставка изображений через `Image` extension.
- ✅ Добавление изображения доступно через slash-меню (`Изображение`) и через toolbar (`Img`).
- ✅ Реализован popup загрузки изображения с drag-and-drop/select-файла.
- ✅ Реализованы состояния ошибок: недопустимый формат и размер более 5 МБ.
- ✅ Поддержаны прямые вставки через drag-and-drop и paste изображений в редактор.
