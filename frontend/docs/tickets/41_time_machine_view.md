## Добавлвение просмотра сохраненной версии страницы

### Описание

При выборе версии из машины времени, отображать сохраненную версию страницы. При этом сохранять возможность переключаться между текущей версией и выбранной версией из машины времени, но как предпросмотр, а не как редактирование. Редактирование должно быть доступно только для текущей версии страницы.
