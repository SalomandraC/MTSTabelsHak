## Добавление контекстного поиска, веторизация документов

## Описание
Я как пользователь хочу иметь возможность искать документы по их содержимому, а не только по названию, чтобы быстрее находить нужную информацию.

Я как пользователь хочу перетягивать/добавлять через меню выбора контекст документов в ai-chat для получения их контекста, чтобы использовать его в диалогах с ИИ. 

Я как пользователь хочу перетягивать/добавлять через меню выбора контекст папок с документами в ai-chat для получения их контекста, чтобы использовать его в диалогах с ИИ.
