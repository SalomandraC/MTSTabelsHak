# Тикет 1: Базово развернуть React проект с tiptap

## Цель

Создать базовый React-проект, который будет служить основой для дальнейшей разработки редактора. Настроить окружение, зафиксировать архитектурные границы и подготовить структуру проекта под рост функциональности. А также развернуть редактор текста на базе Tiptap, который будет ядром нашего приложения с его базовыми фичами: редактор страницы.

## Архитектура

Проект строится по модульному принципу:

- `app/` - провайдеры, роутинг, глобальный store и точка сборки приложения.
- `shared/` - переиспользуемая база: UI, утилиты, API-клиент, общие типы.
- `entities/` - предметные модели и базовая логика домена.
- `features/` - законченные пользовательские действия, например вставка таблицы, autosave или slash-menu.
- `widgets/` - крупные блоки интерфейса, собирающие несколько features и entities.
- `pages/` - экранные компоненты и маршруты.

Для редактора ядро должно быть отделено от React-слоя:

- editor core - схема документа, extensions и команды Tiptap / ProseMirror.
- collab adapter - Yjs и websocket provider.
- persistence adapter - local cache и backend sync.
- UI adapter - React-компоненты для toolbar, панелей и меню.

Такой подход позволяет держать документ как единый source of truth в editor model или Yjs doc, а React использовать только как оболочку.

## Шаги

1. **Создание проекта**
   - Откройте терминал и создайте React-проект на Vite с TypeScript:

     ```bash
     npm create vite@latest my-app -- --template react-ts
     ```
   - Перейдите в созданную папку:
     ```bash
     cd my-app
     ```

2. **Настройка окружения**
   - Установите базовые зависимости проекта:
    ```bash
    npm install
    ```
   - Добавьте инструменты качества кода, например ESLint и Prettier:
     ```bash
     npm install eslint prettier eslint-plugin-react eslint-config-prettier --save-dev
     ```

3. **Определение архитектуры**
   - Создайте структуру папок `src/app`, `src/shared`, `src/entities`, `src/features`, `src/widgets`, `src/pages`.
   - Зафиксируйте правило: все общие UI-элементы и утилиты живут в `shared`, доменные модели - в `entities`, пользовательские сценарии - в `features`.
   - Вынесите редакторное ядро отдельно от React-компонентов, чтобы схема документа и коллаборация не смешивались с отображением.

4. **Подготовка editor core**
   - Определите базовую схему документа и набор расширений Tiptap / ProseMirror.
   - Заранее разделите адаптеры для коллаборации, сохранения и UI, чтобы их можно было менять независимо.

5. **Подготовка ключевых сценариев**
   - Опишите минимум сценариев: редактор страницы, вставка таблицы, slash-menu, autosave, backlinks и collaboration.
   - Убедитесь, что каждый сценарий оформлен как отдельная feature или widget, а не как разрозненная логика в одном компоненте.
