# Добавление шаблонизации страниц

## Описание задачи

Необходимо сформировать систему шаблонов для страниц. Это позволит пользователям создавать шаблоны, которые можно будет использовать для создания новых документов с заранее определенной структурой и содержимым. Шаблоны должны поддерживать передачу параметров, которые могут быть переиспользованы и подставлены в соответствующие места в документе. 

## Требования

1. Пользователь должен иметь возможность создавать шаблоны страниц с определенной структурой и содержимым.
2. Шаблоны должны поддерживать передачу параметров, которые могут быть переиспользованы в документе.
3. Пользователь должен иметь возможность использовать шаблоны при создании новых документов, выбирая их из списка доступных шаблонов.
4. Шаблоны должны быть сохраняемыми и доступными для повторного использования.
5. Интерфейс для создания и управления шаблонами должен быть позволять задавать парматры шаблона и их описание для удобства использования. А также позволять пользователю создавать страницу и в ней добавлять места для параметров шаблона, которые будут заполняться при использовании шаблона для создания новой страницы.
6. Пользователь должен на обынчной странице иметь возможность добавить парамтеры шаблона, которые будут заполняться при использовании шаблона для создания новой страницы. Параметры шаблона должны быть отображены в виде специальных блоков с названием параметра и его описанием, чтобы пользователь понимал, какую информацию нужно ввести при заполнении шаблона. При создании новой страницы на основе шаблона, пользователь должен иметь возможность заполнить эти параметры, и они должны быть корректно подставлены в соответствующие места в документе. 
7. Из обычной страницы пользователь должен иметь возможность создать шаблон, выбрав часть контента страницы и указав, что это будет параметр шаблона. После этого пользователь должен иметь возможность использовать этот шаблон для создания новых страниц, заполняя параметры шаблона при создании новой страницы.
8. Шаблоны должны храниться в базе данных и быть доступными для всех пользователей, у которых есть соответствующие права доступа.(Указывается какой группе пользователей доступны шаблоны) Пользователи должны иметь возможность управлять своими шаблонами, редактируя или удаляя их при необходимости.
9. Долженна быть страничка "маркетплэйса шаблонов", где будут отображаться все доступные шаблоны, с возможностью их фильтрации и поиска. Пользователи должны иметь возможность просматривать детали шаблона, включая его структуру, описание и параметры, а также использовать его для создания новых страниц.

## Криерии приемки

1. Пользователь может создать шаблон страницы, задавая его структуру и содержимое.
2. Пользователь может добавлять параметры шаблона в шаблон страницы и указывать их описание.
3. Пользователь может использовать шаблон при создании новой страницы, заполняя параметры шаблона, и эти параметры корректно подставляются в соответствующие места в документе.
4. Шаблоны сохраняются в базе данных и доступны для повторного использования.
5. Пользователь может управлять своими шаблонами, редактируя или удаляя их при необходимости.
6. На странице "маркетплэйса шаблонов" отображаются все доступные шаблоны, с возможностью их фильтрации и поиска. Пользователи могут просматривать детали шаблона, включая его структуру, описание и параметры, а также использовать его для создания новых страниц.
7. Должны содержаться тесты, покрывающие функциональность шаблонов страниц, включая создание, использование и управление шаблонами. Тесты должны проверять корректность работы с параметрами шаблона и их подстановкой в документ при использовании шаблона для создания новой страницы.
8. Документация должна быть обновлена, чтобы отразить новую функциональность шаблонов страниц, включая инструкции по созданию, использованию и управлению шаблонами. Документация должна быть понятной и доступной для всех пользователей, чтобы они могли легко понять, как использовать шаблоны страниц в своей работе.
