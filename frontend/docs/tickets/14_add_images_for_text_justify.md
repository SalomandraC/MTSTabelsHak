# Добавление изображений для выравнивания текста в редакторе

## Описание

Добавить правильные изображения для действий с выравниванием текста в редакторе. На данный момент используются иконки для выравнивания текста по левому краю, по центру и по правому краю, которые не соответствуют дизайну редактора. Необходимо заменить эти иконки на подходящие изображения, которые будут соответствовать стилю редактора и улучшать пользовательский опыт при работе с выравниванием текста.
